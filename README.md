# Turnos Online — demo

Demo del frontend de una app de reservas de turnos (React + Vite + Tailwind).
Funciona sola en el navegador: trae datos de ejemplo y no necesita backend.

## Probarla

En `/login` hay botones para entrar como **administrador**, **profesional** o **dueño de la plataforma** (contraseña `demo1234`).
Los datos se guardan solo en tu dispositivo; el botón **Reiniciar** (abajo a la izquierda) vuelve a los datos de ejemplo.

## Correrla local

```bash
npm install
npm run dev:demo
```

## Deploy en Vercel

Importar el repo en Vercel. `vercel.json` ya configura el build de demo y las rutas.
